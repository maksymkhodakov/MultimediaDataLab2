# Власні зображення (пункт 4 завдання)

Сцени, типові для Flickr8K. Зображення взято з Wikimedia Commons (зменшено до 960 px по ширині).
Щоб перевірити модель на своїх фото, просто покладіть у цю теку файли JPG/PNG і запустіть `python main.py`
(або `python main.py --caption шлях/до/фото.jpg`).
